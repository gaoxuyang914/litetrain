# LiteTrain 文档索引

本项目采用 **SDD（Spec-Driven Development，规格驱动）+ TDD（Test-Driven Development，测试驱动）** 组织交付。三份核心文档构成 `需求 → 设计 → 测试` 的闭合追溯链。

> 基线说明：以下核心 SDD/TDD 文档最初覆盖 42 项测试；随后新增模型权重导入、流水线预处理/评估、策略上限、流水线恢复、列表筛选和拓扑校验等测试，当前仓库为 **53 项测试**。第 3 节保留最初的 42 项核心测试清单，新增用例以仓库实际测试文件为准。

| [技术实现设计文档](technical-design.md) | 唯一设计事实源 | 架构图、19 张表与状态机、调度/心跳/日志/指标/流水线/Webhook 机制、API 清单、ADR |

## 阅读顺序

1. 先看 [需求规格说明书](requirements-spec.md) §7 验收标准，确认命题基准如何被量化。
2. 再看 [技术实现设计文档](technical-design.md) §1 架构与 §4 核心机制。
3. 最后用 [TDD 测试规格](tdd-test-spec.md) §3 测试清单核对每项需求的可验证性。

根 README 负责环境依赖、启动步骤、接口速查与仓库结构；本文负责规格与设计。
